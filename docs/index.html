功能

像同一台电脑的两块屏幕那样用

不用切输入、不用找另一套键盘。光标往哪去，键盘就跟到哪。

  • 移过相贴的边就跨屏

    按真实摆放拖动屏幕，自动吸附到相邻边缘。多显示器照样排；只有真正贴着的边才能跨过去。

  • 不会一不小心跨过去

    可选按住修饰键才跨屏、贴边停留一会儿才跨屏、角落死区。按着鼠标拖东西时不会切换。

  • 快捷键切换与锁定

    CtrlAlt←→ 直接切到左右相邻的电脑。打游戏或演示时，锁定把键鼠留在当前这台。

  • 共享剪贴板

    在这台复制一段文字，到那台直接粘贴。不会来回回传，也可以单独关掉。

  • ⌘ 与 Ctrl 自动互换

    用 Mac 键盘控制 Windows 时，⌘C 就是 CtrlC，手上的习惯不用改。

  • 断网也不卡键

    断网、超时或出错时，先松开远端所有按键、把键鼠还给本机，再告诉你原因和处理办法。

安全与隐私

键盘输入只在你的局域网里走

你敲的每一个键都可能是密码。所以流界没有服务器、没有账号，也不需要联网登录。

MacBook Pro 书房台式机 不经过任何服务器
局域网直连
设备之间点对点连接，通过局域网广播互相发现，数据不出你的网络。
端到端加密
基于 QUIC 和 TLS 1.3，双方各持一张证书，连接时互相验证身份。
配对过才能控制
只有核对过配对码的电脑才能连接。任意一边移除设备，两边同时删除。

常见问题

装之前你可能想知道

两台电脑必须在同一个网络里吗？

是的，需要连在同一个路由器或 Wi‑Fi 下。流界在局域网里自动发现设备，不经过互联网。条件允许的话用网线连接，跨屏最稳。

Mac 上为什么要打开「辅助功能」和「输入监控」？

流界要读取你在这台 Mac 上的键鼠操作（才能把它送到另一台），被控制时还要模拟按键和点击。这两项权限缺一不可。键鼠数据只在配对过的设备之间加密传输，不会上传到任何地方。

第一次打开时提示「无法验证开发者」或「Windows 已保护你的电脑」？

安装包目前还没有完成苹果公证和 Windows 代码签名，所以系统会拦一下。macOS：在「访达」里右键点流界选「打开」，或到「系统设置 › 隐私与安全性」点「仍要打开」。Windows：点「更多信息」，再点「仍要运行」。

Mac 用 Wi‑Fi 时，鼠标每秒顿一下怎么办？

这是 macOS 的 AWDL（隔空投送、随航等功能用的无线通道）周期性占用网卡造成的。在流界设置里打开「低延迟模式」，有设备连着时会临时关闭 AWDL，断开后自动恢复；也可以改用网线。

能复制图片、拖文件过去吗？支持 Linux 吗？

现在的剪贴板只同步文字。图片和文件的复制粘贴、跨屏拖拽传输、Linux 支持都在后续版本的计划里。

怎么更新？更新时会不会卡住键鼠？

流界启动后会定期检查新版本，发现后在主界面提示。点「立即更新」后会先校验安装包签名，再松开远端按键、把键鼠还给本机，然后安装并自动重新打开。
